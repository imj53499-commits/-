# School YouTube

관리자가 승인한 사람만 들어와서 볼 수 있는 YouTube 뷰어입니다. Cloudflare Pages 무료 플랜에서 돌아갑니다.

- 홈: 들어가면 바로 인기/추천 영상 목록 (카테고리: 음악, 게임, 뉴스, 스포츠 …). 카테고리마다 여러 검색어를 들어올 때마다 다른 순서로 써서 사람마다·방문마다 다른 영상이 나오고, 아래로 내리면 계속 더 불러옴 (무한 스크롤)
- 추천: 최근 본 영상 2개의 관련 영상을 (아래로 내릴수록 그 전에 본 영상들 순서로) 홈(전체)에 인기 영상과 섞어서 보여 줌. 본 영상은 다시 안 나옴. 시청 기록은 브라우저에만 저장 (⚙에서 지우기, 본 쇼츠 목록과 이어보기 위치도 같이 지워짐)
- Shorts: 세로로 한 개씩 넘겨 보기 (휴대폰은 위아래로 밀기, 컴퓨터는 휠이나 ↑↓ 키). 들어올 때마다 다른 검색어 순서로 불러오고, 전에 본 쇼츠(최근 500개)는 건너뜀. 끝나기 한참 전에 미리 더 불러옴. 다음 쇼츠 플레이어를 미리 띄워 둬서 넘기면 바로 재생
- 검색 + 자동완성. 검색 결과와 채널 영상도 아래로 내리면 계속 더 불러옴
- 영상 재생 (YouTube 공식 임베드 플레이어), 설명, 관련 영상. 브라우저가 소리 있는 자동재생을 막으면 음소거로 시작하고 "소리 켜기" 버튼 표시
- 이어보기: 보던 위치를 몇 초마다 브라우저에 저장, 다시 열면 그 위치부터 재생 ("처음부터" 버튼). 홈(전체) 맨 위 '이어서 보기' 줄과 썸네일의 빨간 진행 막대. 거의 다 보면 목록에서 빠짐. 팝업에서도 동작
- 댓글: 영상 아래에 댓글 수와 댓글(작성자, 시간, 좋아요, 답글 수), 아래로 내리면 계속 불러옴
- 자동재생: 영상이 끝나면 관련 영상 중 안 본 영상으로 넘어감 (영상 화면의 스위치로 켜고 끄기, 팝업에서도 동작)
- 팝업으로 보기 (컴퓨터): 영상 화면의 버튼이나 목록 썸네일 위 팝업 아이콘으로 작은 창에서 보기. 팝업에서 단축키(기본 `Q`, ⚙에서 변경)를 누르면 바로 닫힘. 크기는 창 가장자리를 끌거나 오른쪽 위 − + 버튼, `-` `=` 키로 조절 (16:9 유지), 마지막 크기와 위치를 기억. 가리기 단축키를 누르면 팝업도 같이 닫힘
- 채널 페이지
- 다크 모드, 모바일 화면 지원
- 탭 모양: 브라우저 탭·방문 기록에 보이는 제목과 아이콘을 ⚙에서 고르기 (기본 "Google"+회색 아이콘, Google 클래스룸·Google 문서·네이버·위키백과·EBS·빈 새 탭, 또는 사이트 주소를 넣으면 그 사이트 파비콘과 원하는 제목). 영상 제목·검색어는 탭에 안 나옴. 브라우저마다 저장, 팝업에도 적용 (`public/disguise.js`)
- 로그인: 이름(실명)·아이디·비밀번호로 가입 (이메일 필요 없음). 가입하면 **관리자가 승인해야** 쓸 수 있음. 관리자 화면은 `/#/admin`
- 관리자에게 문의: 로그인·가입 화면의 링크(또는 ⚙)에서 로그인 없이 문의를 남기면 관리자 화면 '문의함'에 쌓임 (읽음/삭제). 한 연결당 1시간에 5개까지
- 문의 답장: 관리자가 문의함에서 답장을 보내면, 문의를 보낸 그 브라우저의 로그인·가입·문의 화면에 "관리자 답장이 왔어요" 알림이 뜸 (문의할 때 브라우저에 저장되는 확인 번호로만 볼 수 있음, 30일 보관). '비밀번호 초기화해서 보내기'를 누르면 그 아이디의 비밀번호를 임시 비밀번호로 바꾸고 답장에 넣어 보냄 (복사 버튼). 문의는 누구나 남길 수 있으니 본인인지 확인하고 보낼 것
- 비밀번호: 비밀번호는 해시로만 저장돼 관리자도 볼 수 없음. 대신 관리자가 '비밀번호 초기화'를 누르면 임시 비밀번호가 한 번만 보이고, 그걸로 24시간 안에 로그인하면 새 비밀번호를 정해야 함 (예전 로그인은 모두 풀림, 24시간이 지나면 다시 초기화해야 함). 본인은 ⚙ → 비밀번호 바꾸기
- 화면 가리기: 단축키(기본 `` ` ``, 오른쪽 위 ⚙에서 변경)를 한 번 누르면 검색 시작 페이지처럼 보이는 화면으로 가려지고 영상이 멈춤 (검색하면 실제 Google 검색으로 이동), 다시 누르면 원래 화면으로 돌아오고 영상도 이어서 재생
- 나가기 버튼(오른쪽 위): Google로 완전히 나가기 (주소는 `public/app.js` 의 `EXIT_URL`)

YouTube API 키는 필요 없습니다. 서버(Pages Functions)가 YouTube 내부 API에 익명으로 요청해서 영상 정보를 가져옵니다.

## Cloudflare Pages에 올리기

1. https://dash.cloudflare.com → **Workers & Pages** → **Create application** → **Pages** 탭 → **Import an existing Git repository**
2. 이 저장소와 브랜치 선택
3. 빌드 설정: Framework preset **None**, Build command **비워 두기**
   (출력 폴더 `public` 은 `wrangler.jsonc` 에 들어 있어서 자동으로 적용됩니다)
4. **Save and Deploy** → `https://<프로젝트이름>.pages.dev` 주소가 생깁니다
5. 내 도메인 연결: 프로젝트 → **Custom domains** → **Set up a custom domain** → 도메인 입력
   → 내도메인.한국 등에서 **별칭(CNAME)** 을 `<프로젝트이름>.pages.dev` 로 설정

`/api/*` 는 `functions/api/[[path]].js` (Pages Functions)가 처리합니다.

## 로그인 설정 (처음 한 번)

1. **KV 저장소 만들기**: Cloudflare → **Storage & databases** → **KV** → **Create** (이름 예: `schoolyoutube-db`)
   → 만들어진 KV 의 **ID** 를 `wrangler.jsonc` 의 `kv_namespaces` 에 넣기 (binding 이름은 `DB`)
2. **관리자 비밀번호 정하기**: Pages 프로젝트 → **Settings** → **Variables and Secrets** → **Add**
   → Type **Secret**, Name `ADMIN_PASSWORD`, Value 원하는 비밀번호 → 저장 후 다시 배포
3. `https://<내 주소>/#/admin` 에서 관리자 비밀번호로 들어가 가입 신청을 승인/거절

KV 를 연결하기 전에는 로그인 없이 누구나 볼 수 있고, 연결하는 순간부터 로그인이 필요해집니다. 계정은 KV 에 저장되고, 비밀번호는 PBKDF2 로 해시해서 저장합니다. 로그인 유지 기간은 30일(관리자는 12시간)입니다.

## 터미널로 올리기

```bash
npm install
npx wrangler login
npm run deploy        # wrangler pages deploy
```

## 내 컴퓨터에서 실행

```bash
npm install
npm run dev -- --kv DB --binding ADMIN_PASSWORD=test   # http://localhost:8788
npm test
```

## 구조

| 파일 | 역할 |
|------|------|
| `functions/api/[[path]].js` | Pages 진입점 (`/api/*`) |
| `src/server.js` | `/api/*` 입구: 로그인 확인 후 영상 API 로 전달 |
| `src/auth.js` | 가입, 로그인, 세션, 관리자 승인, 문의함, 비밀번호 초기화·변경 (KV 저장) |
| `src/api.js` | API 라우트 (`/api/home`, `/api/recommend`, `/api/comments`, `/api/shorts`, `/api/search`, `/api/suggest`, `/api/video`, `/api/channel`) + 5분 캐시 |
| `src/youtube.js` | YouTube 내부 API 호출과 응답에서 영상 정보 추출 |
| `public/` | 화면 (HTML/CSS/JS, 빌드 불필요). `popup.html`/`popup.js` 는 팝업 플레이어, `shortcuts.js` 는 단축키, `player.js` 는 플레이어·자동재생·시청 기록 공통 코드 |
| `wrangler.jsonc` | Cloudflare Pages 설정 (출력 폴더 `public`) |

## 참고

- YouTube가 응답 형식을 바꾸면 일부 정보가 안 나올 수 있습니다. 그땐 `src/youtube.js` 의 추출 부분만 고치면 됩니다.
- YouTube가 Cloudflare 서버 IP를 가끔 막을 수 있습니다. 그럴 땐 화면에 "다시 시도" 안내가 나옵니다.
